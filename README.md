# Songy – Clone Tampilan Website Musik

Tugas latihan: membuat ulang (clone) tampilan website streaming musik.
Nama, logo, lagu, dan gambar hanya placeholder, bukan layanan resmi.

## Website asli yang di-clone (pembanding)
https://www.spotify.com

## Isi halaman
Header, hero, daftar lagu populer, form newsletter, footer.

## Interaksi
1. Menu hamburger buka-tutup (layar HP)
2. Tombol play pada kartu lagu
3. Form email dengan validasi
4. Efek hover pada tombol dan kartu

## Cara menjalankan
Buka `index.html` di browser.
